## 2. Rust 행렬 덧셈: `matrix/src/main.rs`

수업 6-3장 8~10쪽처럼 Cargo 사용. `Vec<Vec<i32>>`로 실행 중 정해지는 2차원 행렬을 할당.

```sh
cd matrix
cargo run
# 행 2, 열 2 / A=1,2,3,4 / B=5,6,7,8 입력
cd ..
```

핵심: `let mut`는 변경 가능한 변수, `vec![vec![0; cols]; rows]`는 입력 크기에 맞는 2차원 벡터. 이중 `for`에서 같은 위치의 원소를 더함. 음수도 행렬 요소로 입력 가능. 행·열은 1~100으로 제한.

## 3. 파일 처리: `src/file_demo.c`

```sh
make file_demo
./file_demo
cat demo_dir/hello.txt
ls -l demo_dir/hello.txt
```

강의 7장의 **저수준 파일 처리**. `mkdir` 디렉토리 생성 → `open(...O_CREAT...)` 열기 → `write` 저장 → `close` 닫기 → `open(...O_RDONLY)` 다시 열기 → `read` 읽기 → `stat` 크기 확인. 파일 디스크립터는 열린 파일을 나타내는 정수.

## 4. 재귀 목록: `src/recursive_ls.c`

```sh
make recursive_ls
mkdir -p test/sub
touch test/a.txt test/sub/b.txt
./recursive_ls test
ls -R test
```

`opendir()` 디렉토리를 열고 `readdir()`로 항목을 읽음. `lstat()`과 `S_ISDIR()`로 디렉토리인지 검사한 뒤 `walk()`를 재귀 호출. 목록 순서 및 숨김 항목 처리 등은 `ls -R`과 완전히 동일하지 않음.

## 5. 타자 연습: `src/typing.c`

```sh
make typing
./typing
```

`fgets` 입력, `strlen` 문자 길이, 위치별 비교로 오타 집계, `clock_gettime(CLOCK_MONOTONIC)`으로 경과 시간 측정. CPM = 총 입력 문자 수 × 60 / 시간(초). 삽입/삭제로 발생한 모든 위치 불일치는 오타로 집계됨.

## 6. 부모-자식 프로세스와 시그널: `src/process_signal.c`

```sh
make process_signal
./process_signal
```

강의 8장의 `fork()`는 부모에서 **자식 PID**, 자식에서 **0** 반환. 자식 `kill(getppid(), SIGUSR1)`으로 부모에 신호 전송, 부모는 등록한 처리 함수에서 플래그 변경, `waitpid`로 자식 회수. 단순 구현의 `pause()` 검사 구간에는 시그널 경쟁 조건이 있을 수 있음.

## 7. 익명 파이프: `src/pipe_ipc.c`

```sh
make pipe_ipc
./pipe_ipc
```

`pipe(fds)`에서 `fds[0]`는 읽기, `fds[1]`는 쓰기. 부모가 `write` → 자식이 `read` 하도록 불필요한 파일 디스크립터 닫기. 강의 9장의 기본 예제 구조.

## 8. 파이프 채팅: `src/pipe_chat.c`

강의 9장의 파이프 개념을 **FIFO(이름 있는 파이프)**로 확장. 두 터미널에서 독립 실행 가능. `mkfifo()`로 만들고 `select()`로 키보드/파이프 입력을 동시에 감시.

```sh
# 터미널 A
./pipe_chat a
# 터미널 B
./pipe_chat b
# 양쪽에서 채팅, /quit 입력
# 두 프로그램 모두 끝난 후
./pipe_chat --clean
```

FIFO 생성 경로는 `/tmp/lab2_pipe_a_to_b`, `/tmp/lab2_pipe_b_to_a`. 교육용으로 Linux에서 `O_RDWR`를 사용해 초기 연결 대기를 피함. 여러 줄을 빠르게 보낼 경우 `read()`의 바이트 스트림 특성 때문에 수신 분할/병합 가능.

## 9. POSIX 메시지 큐: `src/mq_chat.c`

```sh
# 터미널 A
./mq_chat a
# 터미널 B
./mq_chat b
# A 먼저 송신, B 답장. /quit 종료
./mq_chat --clean
```

`mq_open()` 큐 열기, `mq_send()` 메시지 보내기, `mq_receive()` 받기, `mq_close()` 닫기, `mq_unlink()` 이름 삭제. `pipe`는 바이트 스트림이고 메시지 큐는 메시지 경계를 유지.

## 10. mmap 파일 복사: `src/mmap_copy.c`

```sh
echo 'Hello Linux' > original.txt
./mmap_copy original.txt copy.txt
cmp original.txt copy.txt
```

`fstat` 원본 크기 → `ftruncate` 복사 대상 크기 → `mmap` 원본/대상 매핑 → `memcpy` 복사 → `msync` 동기화 → `munmap` 매핑 해제. 입력 파일과 출력 파일은 서로 달라야 함.

## 11. D-Bus: `src/dbus_server.c`, `src/dbus_client.c`

```sh
make dbus
# 터미널 A
./dbus_server
# 터미널 B
./dbus_client '안녕하세요'
```

11-1장의 시스템 서비스(D-Bus) 설명에서 통신 방식으로 확장한 **추가 예제**. 강의자료에 서버/클라이언트의 동일한 GIO 소스가 실려 있다는 뜻은 아님. `g_bus_own_name()`으로 이름 소유, `g_dbus_connection_register_object()`로 메서드 등록, `g_dbus_connection_call_sync()`로 호출. 데스크톱/세션 D-Bus 버스가 필요. WSL 등에서는 세션 버스 부재로 실행에 실패할 수 있음.

## 12. 팀 미니쉘: `src/minishell.c`, `src/builtin.c`, `src/builtin.h`

```sh
make minishell
./minishell
```

8장 31~33쪽 `simplesh.c`의 입력→분리→`fork`→`execvp`→`wait` 흐름에 기반. 여기에 `exit`, `&`, `<`, `>`, `|`, `cd`, 직접 작성한 10개 명령을 추가. `builtin.c`는 `ls/pwd/mkdir/rmdir/ln/cp/rm/mv/cat/grep`을 직접 구현, `cd`는 부모 쉘에서 처리.

- `pwd`: `getcwd`
- `ls`: `opendir/readdir`
- `mkdir/rmdir`: `mkdir/rmdir`
- `ln`: `link`로 하드 링크
- `cp`: `open/read/write` 일반 파일 복사
- `rm`: `unlink`
- `mv`: `rename`(다른 파일시스템이면 일반 파일 복사 후 삭제)
- `cat`: `open/read/write`
- `grep`: `getline/strstr`로 단순 문자열 검색
- `cd`: `chdir` (쉘 프로세스 자체에서 수행)

메인 쉘은 `getline` 명령 입력, `strtok_r` 토큰 분리, `fork` 생성, `dup2` 표준 입출력 연결, `pipe` 파이프라인, `waitpid` 대기. `SIGINT/SIGQUIT/SIGTSTP` 기본 동작과 연결하지만 완전한 작업 제어는 미구현. 쉘 문법은 **반드시 공백 구분**하여 입력(`cat file | grep word`와 같이). 고급 Bash 옵션과 정규표현식 grep은 미지원.
